## App landing pages

`/repasito/`, `/thebotanicaleye/`, `/truckrouteplanner/` and `/ludora/` each have an `index.html` landing page (store buttons, promo video or screenshot, features, pricing, help and legal links), generated by `node _tools/make-app-pages.js` with the shared stylesheet `assets/app.css`. Images and videos live in each app's `media/` folder. Edit the text in the script, not in the generated pages.

Truck Route Planner: `truck_route_planner_web/tools/build-legal-pages.js` also writes an `index.html` into its output. When you copy its pages here, leave that file out so the landing page stays.
